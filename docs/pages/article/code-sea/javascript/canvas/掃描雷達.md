## 懶人包
- 雷達拆成四層：背景、同心圓與十字線、會轉的掃描扇形、光點，每一幀全部清掉重畫。
- 掃描光的「拖尾」用 `createConicGradient`（錐形漸層）做，從透明漸變到亮綠色。
- 光點平常是暗的，掃描線經過時把它的亮度設成 1，之後每一幀慢慢衰減。
- 動畫用 `requestAnimationFrame`，元件卸載時記得 `cancelAnimationFrame`。
- 高解析度螢幕要把畫布的實際像素乘上 `devicePixelRatio`，不然線會糊。

## 技術拆解

### Canvas 的角度方向
`Canvas` 的 y 軸往下，所以角度 0 指向右邊（三點鐘方向），角度增加是**順時針**轉，跟數學課本的逆時針相反。一圈是 `Math.PI * 2`。

極座標換成畫布座標：

```ts
const x = centerX + Math.cos(angle) * distance;
const y = centerY + Math.sin(angle) * distance;
```

光點、掃描線都靠這兩行定位。

### 掃描光的拖尾
掃描光不是一條線，是一道「前面亮、後面越來越淡」的扇形。`createConicGradient(startAngle, x, y)` 會從 `startAngle` 開始順時針繞一圈上色，色標的 `0` 到 `1` 就是繞一整圈。

所以我們讓漸層從「掃描線往回 0.6 弧度」開始：色標 `0` 是透明，色標 `0.6 / (Math.PI * 2)` 剛好走到掃描線的位置，給最亮的綠色。再只把這 0.6 弧度的扇形填起來，就是拖尾。

`createConicGradient` 現在主流瀏覽器都支援了，要顧很舊的瀏覽器的話，可以退回用多條透明度遞減的線疊出來。

### 光點什麼時候亮
每個光點記住自己的角度、距離和亮度 `life`：

1. 每一幀算「掃描線的角度」減「光點的角度」，換算到 0～2π 之間。
2. 差距小於一個門檻，代表掃描線剛經過，把 `life` 設成 1。
3. 其他時候 `life` 每一幀減一點點，慢慢暗掉，直到下一圈再被掃到。

門檻要比每一幀轉的角度大，不然轉太快會直接跳過光點。

### 高解析度螢幕
`canvas` 的 `width`／`height` 是**實際像素**，CSS 的寬高只是顯示大小。在 2 倍螢幕上兩者一樣大，瀏覽器就會把 320 像素放大成 640 顯示，線就糊了。解法是把實際像素乘上 `devicePixelRatio`，再用 `ctx.scale` 縮回來，之後畫圖照樣用 CSS 尺寸思考。

## 例子與對比

### 完整的 Vue 元件
```vue
<script setup lang="ts">
import { onBeforeUnmount, onMounted, useTemplateRef } from 'vue';

interface Blip {
    angle: number;
    distance: number;
    life: number;
}

const SIZE = 320;
const TRAIL = 0.6;
const SPEED = 0.03;
const FULL = Math.PI * 2;

const canvasRef = useTemplateRef<HTMLCanvasElement>('radar');

const blips: Blip[] = Array.from({ length: 6 }, () => ({
    angle: Math.random() * FULL,
    distance: 0.2 + Math.random() * 0.75,
    life: 0
}));

let sweep = 0;
let frameId = 0;

function drawGrid(ctx: CanvasRenderingContext2D, center: number, radius: number) {
    ctx.strokeStyle = 'rgba(0, 255, 140, 0.25)';
    ctx.lineWidth = 1;

    for (let i = 1; i <= 4; i++) {
        ctx.beginPath();
        ctx.arc(center, center, (radius / 4) * i, 0, FULL);
        ctx.stroke();
    }

    ctx.beginPath();
    ctx.moveTo(center - radius, center);
    ctx.lineTo(center + radius, center);
    ctx.moveTo(center, center - radius);
    ctx.lineTo(center, center + radius);
    ctx.stroke();
}

function drawSweep(ctx: CanvasRenderingContext2D, center: number, radius: number) {
    const gradient = ctx.createConicGradient(sweep - TRAIL, center, center);
    gradient.addColorStop(0, 'rgba(0, 255, 140, 0)');
    gradient.addColorStop(TRAIL / FULL, 'rgba(0, 255, 140, 0.6)');

    ctx.fillStyle = gradient;
    ctx.beginPath();
    ctx.moveTo(center, center);
    ctx.arc(center, center, radius, sweep - TRAIL, sweep);
    ctx.closePath();
    ctx.fill();
}

function drawBlips(ctx: CanvasRenderingContext2D, center: number, radius: number) {
    blips.forEach((blip) => {
        const diff = (sweep - blip.angle + FULL) % FULL;

        if (diff < SPEED * 2) {
            blip.life = 1;
        } else {
            blip.life = Math.max(0, blip.life - 0.006);
        }

        const x = center + Math.cos(blip.angle) * blip.distance * radius;
        const y = center + Math.sin(blip.angle) * blip.distance * radius;

        ctx.fillStyle = `rgba(0, 255, 140, ${blip.life})`;
        ctx.beginPath();
        ctx.arc(x, y, 4, 0, FULL);
        ctx.fill();
    });
}

function render(ctx: CanvasRenderingContext2D) {
    const center = SIZE / 2;
    const radius = center - 8;

    ctx.fillStyle = '#04140c';
    ctx.fillRect(0, 0, SIZE, SIZE);

    drawGrid(ctx, center, radius);
    drawSweep(ctx, center, radius);
    drawBlips(ctx, center, radius);

    sweep = (sweep + SPEED) % FULL;
    frameId = requestAnimationFrame(() => render(ctx));
}

onMounted(() => {
    const canvas = canvasRef.value;
    const ctx = canvas?.getContext('2d');
    if (!canvas || !ctx) { return; }

    const ratio = window.devicePixelRatio || 1;
    canvas.width = SIZE * ratio;
    canvas.height = SIZE * ratio;
    canvas.style.width = `${SIZE}px`;
    canvas.style.height = `${SIZE}px`;
    ctx.scale(ratio, ratio);

    render(ctx);
});

onBeforeUnmount(() => {
    cancelAnimationFrame(frameId);
});
</script>

<template>
    <canvas ref="radar" class="radar" />
</template>

<style lang="scss">
.radar {
    border-radius: 50%;
}
</style>
```

`useTemplateRef` 是 Vue 3.5 之後的寫法，還在 3.4 以前的專案就改回 `const radar = ref<HTMLCanvasElement | null>(null)`。

### 幾種做法比一比

| 做法 | 優點 | 缺點 |
|---|---|---|
| `Canvas` 2D（這篇） | 畫很多光點也不怕、效果自由 | 要自己處理清除重畫、高解析度、無障礙 |
| `SVG` + CSS 動畫 | 掃描扇形用 `transform: rotate` 就能轉，可以吃 CSS | 光點一多 DOM 就重，「被掃到才亮」的邏輯還是要 JS |
| 純 CSS `conic-gradient` | 一個 `div` 加 `animation` 就有掃描效果 | 光點的互動很難做 |

只要一個裝飾用的掃描效果，純 CSS 就夠了；光點要跟資料連動、數量會變，`Canvas` 比較好收拾。

### 可以再玩的方向
- 光點從 API 來，`distance` 換成真實距離的比例。
- 背景的 `fillRect` 改成半透明的黑色，舊畫面不會馬上清掉，會多一層殘影。
- 尊重 `prefers-reduced-motion`，使用者關掉動畫時就只畫靜態的雷達。

## 結論
雷達看起來很酷，拆開來其實就是「每一幀清掉、按順序重畫、讓角度加一點點」，`Canvas` 動畫大多是這個套路。錐形漸層負責帥，光點的衰減負責有生命感。

畫完記得 `cancelAnimationFrame`，不然雷達會在你看不到的地方繼續掃，~~掃到使用者的電池見底~~。
