## 懶人包
- 原網域 `opshell.com` 因為信用卡過期未續約，被搶註；贖回太貴，決定換新網域。
- 廠商選 **Cloudflare Registrar**：成本價、不賺差價，買完直接整合 DNS、CDN、R2。
- Google Domains 已經被 Squarespace 收購，續約較貴，而且要另外把 NS 指到 Cloudflare。
- 後綴最後選 `.me`：適合個人品牌，技術和攝影都能放。
- 教訓：綁常用的信用卡、開啟自動續約。

## 技術拆解

### 1. 現況分析
- **原網域**：`opshell.com` 因信用卡過期未續約，已被他人搶註。
- **需求**：建立個人技術部落格（`opshell.me`）與攝影集圖床（`images.opshell.me`）。
- **架構**：GitHub Pages（前端）+ Cloudflare R2（圖床）。

### 2. 廠商評估：Cloudflare vs Squarespace
由於 Google Domains 業務已被 Squarespace 收購，目前主要考量如下：

| 比較項目 | **Cloudflare Registrar**（勝出 🏆） | **Squarespace** |
| :--- | :--- | :--- |
| **定價策略** | **成本價（At-cost）**，不賺差價。 | 商業營利，通常較貴。 |
| **續約費用** | 低廉（例如 `.dev` 約 $10-12／年）。 | 較高（約 $20+／年）。 |
| **整合性** | **極佳**。買完直接整合 DNS、CDN、R2。 | **差**。需手動修改 NS 紀錄指向 Cloudflare。 |
| **適合對象** | 開發者、工程師。 | 一般商家、不寫程式者。 |

**結論**：因為後續要用 Cloudflare R2 與 CDN 服務，直接在 Cloudflare 購買網域，可以省去 DNS 搬遷手續，長期持有成本也最低。

價格會變動，實際以各家的價目表為準。

### 3. 網域後綴（TLD）選擇策略
- **`.dev`**：適合技術人員，Google 強制 HTTPS（整個後綴都在 HSTS 預載清單裡），專業感強。
- **`.me`**：適合個人品牌，兼顧技術與攝影（About Me），親切感高。
- **`.design`／`.studio`**：適合強調設計系統（Design System）或職人精神。

**最終決定**：購買 `opshell.me`。

選後綴就像幫店面挑招牌：`.com` 是大馬路旁的店面，大家最熟但早就被佔光；`.dev` 是科技園區，一看就知道你是工程師；`.me` 是自己的工作室，什麼都能放。部落格要放技術文章也要放攝影，工作室剛剛好。

## 例子與對比

### 遇到的問題與解法

| 問題 | 解法 |
| :--- | :--- |
| `opshell.com` 被搶註 | 放棄贖回（價格過高），改註冊更符合個人品牌定位的新後綴 `.me` 或 `.dev`。 |
| 信用卡過期導致服務中斷 | 在 Cloudflare 綁定常用的信用卡，並確認開啟自動續約。 |

::: tip 防止悲劇重演的小清單
- 開啟自動續約。
- 註冊商的帳號信箱要是你真的會看的那個，到期通知才收得到。
- 信用卡換卡後，回去更新所有自動扣款的服務（網域、主機、雲端儲存）。
- 重要網域可以一次續好幾年。
:::

### 在 Cloudflare 買 vs 在別家買再轉過來

| | 直接在 Cloudflare 買 | 別家買、NS 指向 Cloudflare |
| :--- | :--- | :--- |
| DNS 設定 | 自動在同一個後台 | 要去原註冊商改 Nameserver，等生效 |
| 費用 | 成本價 | 看原註冊商 |
| 帳單 | 一個地方 | 兩個地方 |
| 適合 | 本來就要用 Cloudflare 服務 | 已經有網域、懶得轉移 |

## 結論
網域這種東西，平常感覺不到它的存在，直到它不見的那天。這次的教訓是：便宜和整合度選 Cloudflare，後綴選一個符合自己定位的，然後**一定要開自動續約**。

畢竟，被搶註的網域就像前任，想贖回來的價格永遠比當初貴 ~~（而且通常不值得）~~。
