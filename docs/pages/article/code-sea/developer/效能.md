## 懶人包
- 效能就那幾樣：**圖片**（WebP／AVIF、壓縮）、**虛擬捲動**、**非同步元件**、**Web Worker**。
- 外部字型記得 `preconnect`，第一次連線的握手時間省下來，字就早一點出現。
- 動畫用 SVG、CSS 還可以；`Lottie` 每一幀都在主執行緒算，效能很難好看，需要互動式動畫可以看看 `Rive`。
- 剩下的交給 tree shaking：ES Module 讓打包工具知道哪些程式碼沒用到，光這件事就讓效能提升很多。
- 優化前先量：先找到慢在哪，再對症下藥。

## 技術拆解

### 先量，再優化

效能優化像減肥，不先量體重就開始節食，最後只會餓肚子又不知道有沒有用。
打開 Chrome DevTools 的 Lighthouse 或 Performance 面板，看三個 Core Web Vitals：

| 指標 | 量什麼 | 常見的兇手 |
|---|---|---|
| LCP | 最大的內容多久出現 | 大圖、字型、阻塞的 JS |
| INP | 點下去到畫面有反應要多久 | 主執行緒被長任務卡住 |
| CLS | 畫面會不會亂跳 | 圖片沒給尺寸、字型替換 |

下面四大項，剛好就是在對付這幾個兇手。

### 1. 圖片：通常是最大的那一包

一張沒壓縮的首頁大圖，可能比你整包 JS 還大。三件事：

- 格式用 **WebP** 或 **AVIF**，同樣畫質，檔案小很多。
- 上線前**壓縮**，而且尺寸別比顯示的大太多。
- 首屏以外的圖片加 `loading="lazy"`，並給 `width`／`height`，避免載入後畫面亂跳。

### 2. 虛擬捲動：一萬筆資料不要真的畫一萬個 DOM

列表一長，瀏覽器光是排版就喘不過氣。虛擬捲動只渲染「看得到的那幾十筆」，捲動時換內容就好，DOM 數量永遠固定。

### 3. 非同步元件：用到才載入

彈窗、圖表、編輯器這種「不一定會打開」的東西，不需要跟首頁一起下載。拆成非同步元件，打包時會自己切成另一個檔案，用到才載入。路由頁面也是一樣的道理。

### 4. Web Worker：別讓主執行緒做太多事

JavaScript 的主執行緒同時要管畫面、事件和你的程式。大量計算（解析大檔案、排序幾萬筆、影像處理）丟給 Web Worker 在背景做，畫面才不會卡住。這招直接對應 INP。

### 外部字型：preconnect

用 Google Fonts 這類外部字型時，瀏覽器要先跟字型伺服器建立連線（DNS、TCP、TLS），才能開始下載。`preconnect` 讓瀏覽器提早把連線準備好，字就能早一點出現。

### 動畫：SVG、Lottie 與 Rive

- **SVG／CSS 動畫**：瀏覽器原生支援，`transform`、`opacity` 這類屬性還能交給 GPU，效能還可以。
- **Lottie**：設計師在 After Effects 做好、匯出成 JSON，前端用 `lottie-web` 播放。方便是方便，但它是用 JavaScript 每一幀去算、去改 DOM 或 canvas，動畫一複雜、一多，效能就很難好。
- **Rive**：檔案是二進位格式，有自己的 runtime 與狀態機，適合需要互動的動畫（hover、點擊切換狀態）。效能表現與各平台支援，以官方文件為準。

簡單的動畫，能用 CSS 就用 CSS；真的需要設計師做的複雜動畫，再在 Lottie 和 Rive 之間比較。

### 剩下的交給 tree shaking

ES Module 的 `import`／`export` 是靜態的，打包工具在建置時就知道哪些函式有被用到，沒用到的直接刪掉，這就是 tree shaking。
從 CommonJS 走到 ES Module，再加上 `Vite` 這類工具，很多以前要手動處理的效能問題已經被工具解決了。我們要做的，是**別寫出讓它沒辦法搖的程式碼**，例如整包引入一個大函式庫。

## 例子與對比

### 字型 preconnect

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Noto+Sans+TC:wght@400;700&display=swap" rel="stylesheet">
```

字型檔在 `fonts.gstatic.com`，而且是跨來源請求，所以第二行要加 `crossorigin`。網址最後的 `display=swap` 讓字型還沒載完時先用系統字，不會整段空白。

### 圖片

```html
<picture>
    <source srcset="/images/hero.avif" type="image/avif">
    <source srcset="/images/hero.webp" type="image/webp">
    <img src="/images/hero.jpg" alt="首頁主視覺" width="1200" height="630">
</picture>

<!-- 首屏以外的圖片 -->
<img src="/images/card.webp" alt="卡片圖" width="400" height="300" loading="lazy">
```

### 虛擬捲動（VueUse 的 useVirtualList）

```vue
<script setup lang="ts">
    import { useVirtualList } from '@vueuse/core';
    import { ref } from 'vue';

    const allItems = ref(Array.from({ length: 10000 }, (_, i) => ({ id: i, name: `第 ${i + 1} 筆` })));

    const { list, containerProps, wrapperProps } = useVirtualList(allItems, {
        itemHeight: 40 // 每一列的高度要固定，才算得出要畫哪幾筆
    });
</script>

<template>
    <div class="item-list" v-bind="containerProps" style="height: 400px;">
        <div v-bind="wrapperProps">
            <div v-for="{ data } in list" :key="data.id" class="item-list__row" style="height: 40px;">
                {{ data.name }}
            </div>
        </div>
    </div>
</template>
```

一萬筆資料，畫面上同時存在的 DOM 只有十幾列。

### 非同步元件

```ts
import { defineAsyncComponent } from 'vue';

// 打包時會被切成獨立的檔案，第一次用到才下載
const ChartPanel = defineAsyncComponent(() => import('./ChartPanel.vue'));
```

```ts
// 路由也一樣
const routes = [
    { path: '/report', component: () => import('@/pages/ReportPage.vue') }
];
```

### Web Worker（Vite）

::: code-group
```ts [sort.worker.ts]
self.onmessage = (event: MessageEvent<number[]>) => {
    const sorted = [...event.data].sort((a, b) => a - b);
    self.postMessage(sorted);
};
```

```ts [main.ts]
const worker = new Worker(new URL('./sort.worker.ts', import.meta.url), { type: 'module' });

worker.onmessage = (event: MessageEvent<number[]>) => {
    console.log('排好了', event.data.length);
};

worker.postMessage(Array.from({ length: 1_000_000 }, () => Math.random()));
```
:::

`new Worker(new URL(..., import.meta.url))` 是 `Vite` 認得的寫法，建置時會把 worker 一起打包。

### 讓 tree shaking 搖得動

```ts
// 不推薦：整包引入，用一個函式卻帶上整個函式庫
import _ from 'lodash';
_.debounce(fn, 300);

// 推薦：ES Module 版本的具名引入，沒用到的會被搖掉
import { debounce } from 'lodash-es';
debounce(fn, 300);
```
