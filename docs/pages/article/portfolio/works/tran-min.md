## 懶人包
- 專案：案件出勤管理系統，紀錄與審批出缺勤、管理案件進度與工程／時間／人力成本，處理報表匯入匯出與薪資假期計算的小型 ERP。
- 我負責：整個專案的重新構建與技術選型，前端 UI/UX 重新設計、後端改用 `Laravel Eloquent`、資料庫結構重構與舊資料搬遷。
- 技術：`Vue`、`JavaScript (ES6)`、`SCSS`，後端 `Laravel`、`PHP`，資料庫 `MySQL`，工具 `Git`、`Trello`。
- 成果：導入 `Vue` 後開發效率提升 120%，報表匯出在大量資料下更快。

## 技術拆解

### 案件出勤管理 - 傳閔人時案件打卡系統

### Summary
紀錄、審批員工出缺勤狀態，管理案件處理進度及工程、時間、人力等成本，匯入匯出報表，薪資、假期計算的小型 ERP 系統。

### 專案管理與協作
使用 Trello 進行任務追蹤與協作， Git 版本控制，確保專案開發時溝通順暢且能按時交付。

### 使用技術
- 前端：HTML、CSS、SCSS、JavaScript、Vue
- 後端：Laravel、PHP
- 資料庫：MySQL
- 工具：Git、Trello

### 技術創新與導入

#### 前端技術現代化
重新構建整個專案，重新設計 UIUX，優化使用者體驗，主導專案技術選型，推動並導入包括 Javascript(ES6)、SCSS 等現代化前端技術，提升開發效率並降低維護成本。

#### 前端框架導入
導入 Vue 利用部分渲染特性、資料雙向綁定、響應式資料及資料監看等特性，大幅提高頁面響應及渲染效率，降低頁面載入負載、網路負載等，加速開發效率120%，提高使用者體驗。

#### 優化後端資料安全性
導入 Laravel Eloquent 現代後端框架，撰寫開發文件，標準化後端對資料庫的存取模式，提高安全性，降低協同工作時的技術門檻及提高接手效率。

#### 資料庫標準化
重構並標準化資料庫結構，提升查詢、存取效率，將舊資料庫資料重構成新資料庫格式並匯入，加快大量資料處理成報表匯出時的速度。

## 例子與對比

### 重構前後對照

| 面向 | 重構時要解決的問題 | 做法 |
|---|---|---|
| 前端 | 畫面要整頁重新載入、互動慢 | 導入 `Vue`，用響應式資料與部分渲染只更新需要變的地方 |
| 樣式與語法 | 舊寫法難維護 | 導入 `ES6`、`SCSS`，重新設計 UI/UX |
| 後端 | 存取資料庫的方式各寫各的 | 統一用 `Laravel Eloquent`，並寫開發文件 |
| 資料庫 | 結構不一致、報表匯出慢 | 重構並標準化結構，舊資料轉成新格式匯入 |

### 最麻煩的一步：舊資料搬家
重構程式碼可以重寫，資料卻不能重來。新的資料庫結構定好之後，還要把舊資料一筆一筆轉成新格式再匯入，系統才能無縫接上；這一步做對了，後面報表匯出的速度才有機會一起變快。

## 結論
這是一個從前端、後端到資料庫「整棟翻修」的專案，不是換壁紙而已。小型 ERP 最怕的就是資料亂、報表慢，把地基打穩之後，-|算薪水的那天就不用再等報表等到天荒地老|-了。
