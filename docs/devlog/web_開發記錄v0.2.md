# 2026-10-02：開發記錄改寫 v0.2；後台裝上 transitions-dev 的 7 個轉場

**使用者**：上面的記錄在 web_開發記錄v0.2.md，之後的開發也是。在後台執行一下 skill transitions-dev 的 review，沒問題的話做。

- 開了這份 v0.2，把上一節（後台接上有沒有在用、App 版本與公告）從 v0.1 搬過來；v0.1 最後一行指到這裡。
- **review**（對照 transitions.dev 的 32 種，後台原本開關類的東西都是瞬間出現、消失）：
  1 快捷鍵表 → Modal、2 側欄收合 → Card resize、3 側欄待辦數字 → Notification badge、4 深淺色圖示 → Icon swap、
  5 終端機下拉 → Menu dropdown、6 裝置／回報詳情 → Panel reveal、7「載入中…」→ Shimmer text、
  8 三組分段切換 → Tabs sliding、9「✓ 已更新」與「已複製」→ Text states swap。
  **裝了 1～7。8、9 不做**：分段切換要量位置、API 控制台那組在可收合的側欄裡，第一次畫容易跳，工具型的後台划不來；
  提示訊息是頁面上方的一行字，不是浮在角落的，換成 toast 會改版面。
- **怎麼裝**：配方放在 `theme/scss/_transitions.scss`（`@use` 進 style.scss），結構照原文（哪些屬性動、開關分開、`prefers-reduced-motion` 保護），
  曲線換成專案的：一般的 `--cubic-FiSo`（跟 App 同一條），彈的（badge 的 pop）`--cubic-SiRo`。時長沿用配方：網站還沒有自己的時長刻度。
  - Modal：`<dialog>` 關著是 `display: none`，先 `showModal()`、強制排版一次再加 `is-open`；Esc（`cancel`）、點背景、關閉鈕都走同一個關法，播完 `--modal-close-dur` 才 `close()`。
  - Dropdown：終端機下拉從 `v-show` 改成一直掛著，focus 時 `is-open`、離開時 `is-closing` 播完再拿掉；關著時 `aria-hidden`。
  - Panel reveal：`usePanelReveal.ts`（裝置、回報兩頁共用）。詳情是 `v-if` 掛的，先畫成關著、兩格後才打開；關的時候先 `data-open=false`，播完才拿掉。
    **只在從沒有到有、關掉時播**，換看另一台不重播。面板很高，位移只用 24px。
  - Badge：外框一直在、絕對定位（展開時在快捷鍵左邊、收合時在圖示右上角），數字出現或歸零都不讓字跳位。
  - Icon swap：**圖示晚兩格才換**。VitePress 切深淺色的那一格會插一段「全站 transition: none」的樣式（避免整頁顏色漸變），同一格換圖示，轉場會被吃掉（第一次量就是這樣，60ms 時已經換完）。
  - Card resize：側欄那一欄改成 `auto`，寬度寫在側欄自己身上，收合時轉 `width`。
  - Shimmer：10 個「載入中…」加 `t-shimmer` 與 `data-text`，亮帶顏色接 VitePress 的 `--vp-c-text-3`／`--vp-c-text-1`，深淺色自己跟著。
- 驗證（無頭 Edge，量轉場中途的數值）：modal 40ms 透明度 0.30、縮放 0.97；dropdown 同樣；詳情 80ms 還在往上滑（19px、模糊 1.6px），換看別台時透明度 1 不重播，關掉播完才拿掉；
  側欄 120ms 寬 111px → 60；圖示 70ms 兩個 0.84／0.16 交叉；badge 0→1 時 60ms 縮放 0.68、最後 1；shimmer 2 秒循環。
  模擬「減少動態」：全部直接到位、shimmer 不跑。
- **坑**：一個正規式把 `data-text="載入中…"` 的結尾引號吃掉，HTML 壞了之後又跑了 `eslint --fix`，它把 9 個檔案的模板改得亂七八糟（有一個動了 196 行）。
  全部還原成 HEAD 再重新套用；之後**先確認模板解析得過，才跑 `--fix`**。
