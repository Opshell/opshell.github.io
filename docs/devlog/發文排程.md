接著照它印出來的指令 build、commit、push 就上線了。想插隊就把那一行搬到最上面；想跳過就把那行刪掉或改成一般文字。

## 寫新文章

```bash
pnpm new-post "標題" ai          # AI 專區，分類 AI
pnpm new-post "標題" ai 心得     # AI 專區的「心得」分頁
pnpm new-post "標題" code-sea/vue
```

骨架開頭有一段「這篇的脈絡」：寫為什麼寫這篇、遇到什麼狀況、寫給誰看。寫好後把這篇加進上面的佇列。
